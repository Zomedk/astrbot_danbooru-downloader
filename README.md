# AstrBot Danbooru 美图插件

这是服务器当前使用的 AstrBot Danbooru 插件版本。插件从 Danbooru 查询角色图片，下载后进行图片处理，再通过 AstrBot 消息链发送。

## 功能

- 支持角色名和角色别名查询
- `美图` 获取随机图片
- `新图` 按最新排序获取一批图片，再从候选批次中随机选择
- 支持全年龄、R18、单人和高评分筛选
- 按查询条件优先避开最近发送的 3 张图片
- 普通图片使用图片消息发送
- R18 图片使用合并转发，并设置 30 秒发送冷却
- 网络请求和图片压缩放到线程中执行，避免直接阻塞 AstrBot 事件循环
- 发送后延迟删除临时图片

## 命令

```text
美图 <角色名>
美图 <角色名> safe
美图 <角色名> r18
美图 <角色名> 单人
美图 <角色名> 筛选

新图 <角色名>
新图 <角色名> safe
新图 <角色名> r18
新图 <角色名> 单人
新图 <角色名> 筛选
```

参数可以组合使用，例如：

```text
美图 胡桃 单人 safe 筛选
新图 雷电将军 r18
```

## 配置

在 AstrBot 插件配置中填写：

| 配置项 | 说明 |
|---|---|
| `username` | Danbooru 用户名 |
| `api_key` | Danbooru API Key |
| `proxy` | 可选 HTTP 代理，例如 `http://127.0.0.1:7890` |
| `new_limit` | `新图` 候选批次大小，默认 100，范围 1-200 |
| `send_mode` | 配置字段已保留；当前服务器版本按照图片类型固定发送策略，未根据此字段切换行为 |

默认查询不额外添加评级过滤。使用 `safe` 时添加 `rating:g`，使用 `r18` 时添加 `rating:e`，使用 `筛选` 时添加 `score:>30`。
`新图` 默认使用 `order:id_desc` 获取 100 张候选图片后随机选择；候选数量可以在后台通过 `new_limit` 调整。

## 安装

1. 将插件目录放入 AstrBot 的 `data/plugins/`。
2. 确保目录中包含 `main.py`、`mapping.py`、`metadata.yaml` 和 `_conf_schema.json`。
3. 在 AstrBot 插件配置页面填写 Danbooru 账号信息。
4. 重载或重启 AstrBot。

## 注意事项

- 合并转发依赖消息平台支持，当前主要面向 OneBot v11。
- 图片下载、压缩和发送都可能受 Danbooru、代理和 QQ 协议端限制。
- 临时文件默认写入 `/tmp/astrbot_img`，发送后延迟清理。
- 单张下载大小限制为 32 MiB，图片像素数限制为 4000 万；超过限制或无法解析的图片会跳过。
- R18 发送使用代码中的固定转发节点信息。迁移机器人账号时应同步检查该部分配置。

## 项目文件

```text
main.py             AstrBot 插件入口和命令处理
mapping.py          角色、别名和 Danbooru 标签映射
metadata.yaml       AstrBot 插件元数据
_conf_schema.json   插件配置页面定义
```

## 开发建议

源码以 GitHub 仓库为准，服务器只部署 GitHub 中已经提交并打过标签的版本。服务器运行目录中的 `.bak`、缓存图片和临时文件不应提交到仓库。
